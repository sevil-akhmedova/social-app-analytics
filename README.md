# Аналитика социального приложения

*Продуктовая аналитика приложения с лентой новостей и мессенджером.*

В приложении объединены два сервиса: лента новостей, где пользователи просматривают публикации и ставят лайки, и мессенджер для обмена сообщениями.

В рамках проекта исследуются пользовательская активность, вовлечённость и удержание аудитории, проводятся A/B-тесты, прогнозируются продуктовые метрики и автоматизируется отчётность.

Проект основан на практических заданиях Karpov.Courses «Симулятор аналитика».

## Проекты

Каждая работа представлена в отдельном разделе с описанием задачи, реализацией и результатами.

## О данных

Анализ проводился на данных приложения из двух основных таблиц ClickHouse:

- `feed_actions`: действия пользователей в ленте новостей, включая просмотры (`view`) и лайки (`like`).
- `message_actions`: события мессенджера с информацией об отправителях и получателях сообщений.

Данные обновлялись ежедневно, что позволяло отслеживать динамику метрик и исследовать изменения пользовательского поведения.

Доступ к исходной базе и Superset сейчас закрыт. Поэтому для первых исследований сохранены оригинальные дашборды и результаты анализа. Там, где исходные SQL-запросы не сохранились, это отмечено в описании соответствующей работы.

**Источник данных:** Karpov.Courses, «Симулятор аналитика».
